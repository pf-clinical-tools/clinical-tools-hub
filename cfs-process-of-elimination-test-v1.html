Rockwood Clinical Frailty Scale (CFS) Interactive Assessment

Frailty scoring should reflect the patient's usual baseline function before the acute illness or injury rather than the temporary deterioration present on admission.

Use this tool to support Clinical Frailty Scale scoring. It should not replace clinical judgement.

Important: Frailty scoring should reflect the patient’s actual baseline function prior to the acute illness or fracture and not the temporary deterioration seen on admission.

Start at CFS 9 and work down. Select Yes when the descriptor matches the patient’s baseline function. Select No to move to the next category.
